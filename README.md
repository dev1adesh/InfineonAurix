# Infineon AURIX TriCore Firmware

Firmware projects for the Infineon **AURIX TC397** (six TriCore cores), from my embedded systems work with automotive-grade BMS hardware.

## Projects
- `CAN_Communication/` — multi-core MCMCAN setup on the TC397 kit (`MCMCAN.c/.h`, per-core `CpuN_Main.c`)
- `UART_TC397/` — ASCLIN shell UART communication (`ASCLIN_Shell_UART.c/.h`)
- `BMScontrol` — BMS control notes/code

## Stack
Embedded C · AURIX TC397 · CAN (MCMCAN) · UART (ASCLIN) · Tasking toolchain
